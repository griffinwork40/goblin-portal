# Goblin Portal

## What This Is

A native macOS terminal written in Swift 6 / AppKit, deliberately with **no AI features** — built to host [`agent-afk`](https://github.com/griffinwork40/agent-afk)'s REPL properly. The agent lives *in* the terminal; the terminal is a fast, correct, native window that gets out of the way. The bar is "beautiful and user-friendly as hell" before clever. Rendering is [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm) (vendored, v1.15.0 + nineteen patches); everything else is AppKit files, none over 350 LOC (148 app + 1 CLI as of 2026-10-08). Personal project, private repo `griffinwork40/goblin-portal`, single `main` branch.

Naming: the app was renamed from MacTerminal to **Umber** on 2026-07-27 (commit `faf1291`), then from Umber to **Goblin Portal** on 2026-09-15 (commit `caeb9167`). Code, scripts, bundle id, env var, and config path are all `goblin-portal`/`GoblinPortal`/`GOBLIN_PORTAL_`. The theme preset `"umber"` survives as an easter egg. The checkout directory was renamed from `mac-terminal` to `umber` on 2026-08-18. Remaining `MacTerminal`/`MT_DIAG` strings in `.afk/` are historical records, not stale code; `MacTerminalView` in `KeyBindings.swift` is SwiftTerm's own upstream type name.

**Releases** are cut with `app/Scripts/cut-release.sh`; when to cut, which number, and how to recover a half-done release are in [`RELEASING.md`](RELEASING.md).

**There is no test target and no CI.** The 64 `check-*.sh` scripts (plus `verify-vendor.sh`) and `GOBLIN_PORTAL_DIAG` are the whole verification surface — see `app/README.md` ("Checks") for the rationale. Current gate count: `ls Scripts/check-*.sh | grep -v '-falsify.sh$' | grep -v '-baseline.sh$' | wc -l` = 64. `check-keys-e2e.sh` needs Accessibility permission (exits 2 without it, 3 if app never frontmost); prefer `check-keybindings.sh` for routine work. `check-reflow.sh` and `check-altbuffer-resize.sh` link `SwiftTerm.o` and run `swift build` themselves; exit 1 = assertion failure, 2 = environmental. Full gate-count changelog and per-gate falsification narratives: [`docs/gates-ledger.md`](docs/gates-ledger.md).

There is no `.xcodeproj` by design — the project stays all-text, diffable, and scriptable. Do not add one.

**First-party source stays all-text and diffable.** Everything in `app/Sources/GoblinPortal/` is readable, greppable, and under the 350-LOC ceiling. `app/Package.resolved` is committed (a `!app/Package.resolved` negation in `.gitignore`). The libghostty probe (Phase 2, 2026-07-31 -- 2026-08-18) added `libghostty-spm` `.exact("1.3.2")` as a 51.8 MB prebuilt `GhosttyKit.xcframework`; that dependency was removed with the ghostty engine (PR #95, 2026-08-18). The probe plan's convention-loss note in §7 risk 3 is historical record.

Three of the `patches/swiftterm/` patches (there are twenty now; `0012`, the Metal emoji fix, `0013`, the combining mark after wide char fix, `0014`, the ligature-disable feature, `0015`, the scrollbar-thumb proportional-floor fix, and `0016`, the slow-producer display-link pause, are further patches whose causes were found by reading the vendored renderer) fix **upstream defects found by reading vendored source** — `0002` (#494 scrollback reflow), `0003` (the alt-buffer tmux bleed) and `0004` (an ungated release-build `abort()`). None of those three could have been found, let alone fixed locally, against an opaque binary.

**There are two tab levels, on purpose** (plan §12.3, branch (C) — settled 2026-07-27).

- **Spaces = native macOS window tabs.** One `NSWindow` per project root. Because these are real system tabs, ⌘⇧[ / ⌘⇧] cycling, the tab overview, drag-to-reorder, drag-out-to-detach and Merge All Windows work without being implemented. **Do not replace this level with a custom tab bar** — it is load-bearing, and it is why (C) was chosen over a full in-window strip.
- **Documents = a hand-rolled strip** (`DocumentTabStrip`) inside each Space. This level *must* be custom: a system window tab **is** an `NSWindow`, so a mixed terminal/editor strip would give every document its own `contentView` and there could be no shared, full-height sidebar (plan §12.2). The strip is hidden at a single document so one-terminal Goblin Portal still just looks like a terminal.

Adding a new document kind (editor, diff, observer panel) means writing a `SpaceDocument` conformer — **not** touching the container. That is the whole payoff of the restructure.

**Keymap:** ⌘N new Space · ⌘⇧N new Space in a new window · **⌘O open folder as a Space** · ⌘T new document · ⌘W close document (falls through to the Space when it is the last; collapses a split first when one exists) · ⌘⇧W close Space · ⌘⌥← / ⌘⌥→ cycle documents · ⌘1–⌘9 select document · ⌘B toggle sidebar · **⌘⇧E show Explorer sidebar · ⌃⇧G show Source Control sidebar** · ⌘0 Actual Size (predates the above) · **⌘⇧\\ split right · ⌘⇧- split down** (tmux-inspired: `|` and `-`) · **⌘⇧H/J/K/L focus pane left/down/up/right** (tmux-inspired vim nav) · **⌘Z / ⌘⇧Z undo & redo** (editor only; answered by NSWindow's undo manager, not by us) · **⌘F find, ⌘G / ⌘⇧G next & previous, ⌘E use selection** · **⌥⌘F find and replace** (editor only — SwiftTerm's `validateUserInterfaceItem` greys it out over a terminal, which is correct: scrollback is a transcript) · **⌃⌘F full screen** · **⌘⇧E / ⌃⇧G sidebar Explorer / Source Control** · in the tree: **Return/F2 rename, ⌘⌫ Move to Trash (confirms), ⌘X/⌘C/⌘V files** (moved off ⌘F when search landed — ⌃⌘F is the macOS default anyway) · **⌘⌫ Move to Trash** (file tree, via `FileTreeOutlineViewKeyDelegate`) · **Return / F2 rename inline** (file tree) · **⌘M Minimize** (standard macOS window, `performMiniaturize:`, #164) · **⌘K Clear Buffer** (focused terminal only — erases scrollback + screen via RIS, redraws prompt; `clearBuffer:` on `GoblinPortalTerminalView`; does NOT conflict with ⌘⇧K focus-pane-up because `KeyBindings.controlBytes` guards on `intent == [.command]` exactly and ⌘⇧K's modifier set adds Shift, #164) · **⌥⌘H Hide Others** (`hideOtherApplications:`, standard App menu, #164) · **⌘? **Search is SwiftTerm's, not ours.** `performFindPanelAction` is `@objc open` (`Mac/MacTerminalView.swift:2169`) and dispatches `NSFindPanelAction` tags to `showFindBar` / `performFind(next:)`; `validateUserInterfaceItem` (`:2119`) already whitelists showFindPanel/next/previous. - **The reason this repo gave for shipping no palette was STALE, and was corrected 2026-08-03.** The claim — repeated in `AFK.md`, `Config.swift`, `StarterConfig.swift`, `README.md` and `GitStatus+Presentation.swift` — was that "any theme regenerates ANSI 16–255 by interpolating bg/fg, replacing the standard 256-colour cube". - **`closeOnShellExit`: `"clean"` (default), `"always"`, or `"never"`.** Controls what happens when a terminal's shell exits. `"clean"` (Terminal.app's default): close the pane on a clean exit (code 0), keep it on a nonzero exit or signal so the user can read the last output. `"always"`: always close (pre-T2.2 behaviour). `"never"`: always keep the pane until the user explicitly closes it. Measured +2 rows at 1100x680 with the sidebar showing, +0 collapsed. Unknown values warn and fall back to standard; ⌘R applies it live both ways. ## Conventions

- **Hard ceiling: no source file over 350 LOC.** Set 2026-07-28, enforced by `./Scripts/check-file-size.sh` (exit 1 on violation, warning band at 315). This is a maintainability rule, not an aesthetic one: with no test target and no CI, correctness here depends on a reader — human or agent — holding a whole file in context before editing it, and a 550-line AppKit file spends most of an agent's working context establishing what is safe to touch. The failure mode is silent, because the agent then edits from a partial read. When a file approaches the ceiling, find its seam and pull one whole concern out (a delegate conformance, a model type, a drawing routine, a UserDefaults store); do not raise `LIMIT`. Every new file gets a header comment naming what it owns, and the file table above gets updated in the same commit — a stale map costs an agent the same context the split just bought back. Prose is exempt: `.afk/plans/*.md` are single arguments meant to be read end to end.
- **Prefer one concern per file, and a seam over a flag.** New behaviour that plugs into an existing type should arrive as a new file conforming to an existing protocol (`SpaceDocument` is the model — see `FileViewerPane`, added without the container learning anything about it), not as another branch inside a type that already has a job.
- **Comments explain *why*, and cite their evidence** — vendor source lines (`Terminal.swift:725`), upstream issue numbers (SwiftTerm #494), cross-repo files, plan sections (`plan §4.1`). Match this density: nearly every non-obvious line carries a rationale. A patch with no *why* comment on a non-obvious line is under-written for this repo.
- **Config parsing fails soft, per field.** `AppConfig.load()` never throws: a bad value degrades to the default and appends a warning, printed to stderr and shown in the non-modal config-warnings banner (`ConfigWarningPresenter`, #166 T1.5) so a Finder/Dock launch sees it too. Six bad fields ⇒ six warnings and a working terminal. Preserve this — do not introduce a throwing config path.
- **One source of truth for defaults**: `AppConfig.defaults()` in `Config.swift` and the `defaultFontSize` / `minFontSize` / `maxFontSize` statics in `Config.swift` (lines 231, 236, 237). Read them; never re-hardcode.
- **Keybindings live in one table** (`KeyBindings.swift`), not scattered switches — deliberately, so `check-keybindings.sh` can compile the shipped file directly. Adding a chord means editing the table and the truth table.
- `@MainActor` on every type; `@preconcurrency` on the SwiftTerm conformance with an inline note why. **No `Sendable` annotations** — the one exception is `DirectoryListing.lister`, a `@Sendable (URL) -> [DirectoryEntry]` closure type required to cross from the `@MainActor` var to a background `DispatchQueue.global()` call in `FileTreeViewController+Loading.swift`. That is the documented boundary; do not add more.
- **Tree reload shapes**: `refresh()` is async — it launches a background listing and lands on main; callers in the same turn that need the reload complete must call `refreshSynchronously()` instead. Any synchronous tree change that invalidates an in-flight async listing must call `invalidatePendingLoads()` (bumps `treeLoadGeneration`) so the stale result is dropped when it lands. Both patterns are enforced by `check-tree-refresh.sh` cases STALE-DROP and MUTATION-INVALIDATES.
- **Offscreen harnesses that pump the run loop** must start with `RunLoop.main.perform { … }`, not `DispatchQueue.main.async { … }`. `DispatchQueue.main.async` is processed only after the current run loop iteration exits; `RunLoop.main.perform` is processed in the next iteration of the SAME run loop spin, which is what lets `pump()` in the check-*.sh harnesses observe state that was set synchronously in the preceding line. Mixing them produces a subtle ordering inversion that reads as a gate flake.
- **Falsification must mutate a copy of SHIPPED source.** Use `cp -cR app/ <tmpdir>/app/` (APFS clonefile; fast) and apply the mutant to the copy; the gate binary re-runs against the copy via `GATE_SRC_DIR`. Never mutate the shipped file in place. The harness must exit 2 (not 0) when no mutant ran — a falsify run in which nothing executed exits 2 so a zero-mutant run cannot silently report success. A mutant counts as caught only when its declared case fails; exit 1 from a different case is WRONG-CASE and counts as missed. A mutant that does not compile or whose pattern no longer applies exits 2 (environmental), not caught. This lesson was learned the hard way: two lanes in the parallel work shipped false-green falsification — one mutated the harness's own expectations rather than the shipped source, one counted compile-failed mutants as "skipped" and exited 0.
- Force-unwraps are confined to compile-time-known constants (literal UTF-8, literal hex palettes). **No `try!`** — filesystem writes use `try?`. Keep it that way.
- `GoblinPortal` is the only prefix in code; the diagnostic env var is `GOBLIN_PORTAL_DIAG` (any non-nil value).
- Commit style: conventional-ish, lowercase, scope in parens, em-dash rationale — `feat(app): make font size actually configurable — 14pt default, zoom that sticks`.
