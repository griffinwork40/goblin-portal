feat(app): move child sorting off main thread (#207)

`DirectoryListing.sorted(_:)` owns the one localized comparator
(dirs first, hidden last within group, `localizedStandardCompare`).
Async loaders in `FileTreeViewController+Loading.issueListing` call
it inside the `DispatchQueue.global` block, before the `@MainActor`
Task, so sort work never runs on main. Synchronous
`reloadChildren()` calls it too, keeping one rule everywhere.

`FileNode.reconcile` is stripped of its inline `.sorted {}` closure —
entries arrive pre-ordered and the function preserves them as-is.
`NodeIdentity` and staleness-generation logic are untouched.
